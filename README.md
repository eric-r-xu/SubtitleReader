# Subtitle Reader

A macOS menu bar app that reads the text in a screen area you choose aloud — handy for subtitles. Runs on both Apple silicon and Intel Macs (macOS 13+). No Xcode needed.

**Works best with white text on a black background. English only.**

## Install
1. Download [Subtitle-Reader-1.0.dmg](Subtitle-Reader-1.0.dmg), open it, and drag **Subtitle Reader** into Applications.
2. On first launch, right-click the app → **Open** and confirm (it is not notarized). On macOS 15 and later, use System Settings → Privacy & Security → **Open Anyway** instead.
3. Allow **Screen Recording** in System Settings → Privacy & Security → Screen Recording, then relaunch the app.

## Use
From the menu bar icon: **Select Area**, **Resume Last Area**, **Stop Reading**. **Follow White-on-Black Text** reads only subtitle-style text inside the area. **Voice**, **Speed** and **Volume** change how it sounds.

Source and build scripts: [assortedTooling/SubtitleReader](https://github.com/eric-r-xu/assortedTooling/tree/main/SubtitleReader).
